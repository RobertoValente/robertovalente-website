Refiz o meu site de raiz. A ideia foi simples: menos coisas, mais personalidade.

## O que mudou

- **Português e inglês.** Cada página existe nas duas línguas.
- **Blog.** Cada post é um ficheiro `.md` no repositório. Escrever um post é fazer um commit.
- **Contacto.** Um formulário simples: nome, email e mensagem.

## Porquê Markdown

Não preciso de uma base de dados para escrever. Um ficheiro, um commit, e o post está publicado:

```bash
git add content/blog/pt/novo-site.md
git commit -m "post: novo site"
git push
```

Sempre a aprender, sempre a construir.
