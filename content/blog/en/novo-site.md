I rebuilt my website from scratch. The idea was simple: fewer things, more personality.

## What changed

- **Portuguese and English.** Every page exists in both languages.
- **Blog.** Each post is a `.md` file in the repository. Writing a post means making a commit.
- **Contact.** A simple form: name, email and message.

## Why Markdown

I don't need a database to write. One file, one commit, and the post is live:

```bash
git add content/blog/en/novo-site.md
git commit -m "post: novo site"
git push
```

Always learning, always building.
